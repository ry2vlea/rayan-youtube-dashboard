# RAYAN – 365 Days to Rebuild My Life
Channel dashboard (v2). Live: https://ry2vlea.github.io/rayan-youtube-dashboard/

- Single dependency-free `index.html`; data is saved only in your own browser (localStorage), nothing is stored here.
- Add to Home Screen on iPad/iPhone (Safari → Share → Add to Home Screen) for an app-style, offline-capable version (`manifest.webmanifest`, `sw.js`, `icons/`).
- Use Export/Import JSON in the Data section to move data between devices.
